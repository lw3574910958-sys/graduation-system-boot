1. 使用 `storedPath` 保存相对路径

**关键代码**：
```typescript
// 保存相对路径
const fileUrl = response.data.storedPath || response.data.url || response.data.name
existingFile.url = fileUrl

// 编辑时初始化文件列表
watch(() => props.value, (newValue) => {
  if (newValue && typeof newValue === 'string') {
    fileList.value = newValue
      .split(',')
      .map((item) => item.trim())
      .filter((item) => item)
      .map((item) => ({
        name: item.substring(item.lastIndexOf('/') + 1),
        url: convertPathToUrl(item),
        status: 'success',
      }))
  }
}, { immediate: true })
```

### 3. 列表显示工具函数（utils.ts）

**功能**：将数据库路径转换为文件列表，用于列表页面显示

**修复内容**：智能添加 `/files` 前缀

**关键代码**：
```typescript
export const urls2FileList = (url: string | null | undefined): FileItem[] => {
  if (!url || typeof url !== 'string') {
    return []
  }
  return url
    .split(',')
    .map((item) => item.trim())
    .filter((item) => item)
    .map((item) => ({
      name: item,
      url: item.startsWith('/files') 
        ? normalizePath(constants.BASE_URL, item)
        : item.startsWith('/')
          ? normalizePath(constants.BASE_URL, '/files' + item)
          : normalizePath(constants.BASE_URL, '/files/' + item),
    }))
}
```

### 4. 头像显示组件（Avatar.vue）

**功能**：在列表页面显示用户头像

**修复内容**：添加 `/files` 前缀处理和 URL 拼接

**关键代码**：
```typescript
const avatarUrl = computed(() => {
  if (!props.avatar) {
    hasAvatar.value = false
    return ''
  }
  
  if (props.avatar.startsWith('http')) {
    return props.avatar
  }
  
  const pathWithPrefix = props.avatar.startsWith('/files')
    ? props.avatar
    : props.avatar.startsWith('/')
      ? '/files' + props.avatar
      : '/files/' + props.avatar
  
  hasAvatar.value = true
  return `${import.meta.env.VITE_API_BASE_URL}${pathWithPrefix}`
})
```


## 核心设计原则

### 1. 相对路径存储

**原则**：数据库只存储相对路径，不存储完整 URL

**好处**：
- ✅ 环境无关性（开发、测试、生产环境通用）
- ✅ 数据库迁移不受域名变化影响
- ✅ 支持灵活部署（本地文件、CDN、OSS 等）

### 2. 三层路径转换

**原则**：在三个不同阶段进行路径转换，确保所有场景都正确

**层级**：
1. **FileUpload.vue**（上传/编辑）：保存相对路径，编辑时回显
2. **urls2FileList()**（列表显示）：转换为完整 URL
3. **Avatar.vue**（组件显示）：转换为完整 URL

### 3. 智能前缀处理

**原则**：兼容多种路径格式，自动添加 /files 前缀

**规则**：
- `avatar/xxx.jpg` → `/files/avatar/xxx.jpg`
- `/avatar/xxx.jpg` → `/files/avatar/xxx.jpg`
- `/files/avatar/xxx.jpg` → `/files/avatar/xxx.jpg`（不变）

### 4. 时间戳文件名

**原则**：使用时间戳格式生成文件名，保留历史记录

**格式**：`yyyyMMddHHmmssSSS.jpg`

**好处**：
- ✅ 文件名唯一，不会冲突
- ✅ 可以从文件名看出上传时间
- ✅ 保留历史头像记录
